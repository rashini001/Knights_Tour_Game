
# ♞ Knight’s Tour Problem – Java GUI Application

This Java-based desktop application solves the **Knight’s Tour problem** using two algorithmic approaches: **Backtracking** and **Warnsdorff’s Rule**. The game is fully interactive, animated, and uses a MySQL database to store and display user performance results.

## 🚀 Features

- 🔁 **Random knight starting position**
- 📍 **8×8 chessboard with animated knight movement**
- 🧠 **Backtracking & Warnsdorff’s Rule algorithms**
- 🎨 **Dark/light theme toggle**
- 🧾 **Move counter and status display**
- ✅ **Victory/Failure detection with popup**
- 🗃️ **Results saved and displayed from MySQL DB**
- 👤 **Player name selection and history**
- 🧩 Built with the **Model-View-Controller (MVC)** architecture


## 🛠 Technologies Used

- Java SE (Swing)
- JDBC (MySQL Integration)
- MySQL (with knight_results table)
- SwingWorker for animations
- MVC Design Pattern
